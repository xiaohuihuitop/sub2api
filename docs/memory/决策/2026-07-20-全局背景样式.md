# 全局背景样式

- 状态：已确认
- 日期：2026-07-20
- 结论：保留旧版暖色控制台背景：浅色模式为石色底、半透明网格层和顶部主色渐变；深色模式保留低透明度网格层。
- 根因：`style.css` 的全局 `body` 背景已经恢复，但 `AppLayout.vue` 被官方 `bg-gray-50` 容器覆盖，并移除了网格透明度与顶部渐变层。
- 正确做法：同步官方后必须同时检查 `frontend/src/style.css` 和 `frontend/src/components/layout/AppLayout.vue`；不能只恢复全局 `body` 背景。
- 验证：`AppLayoutBackground.spec.ts` 断言石色容器、网格透明度和顶部渐变层；运行类型检查、lint 和前端生产构建。
- 相关文件：
  - `frontend/src/style.css`
  - `frontend/src/components/layout/AppLayout.vue`
  - `frontend/src/components/layout/__tests__/AppLayoutBackground.spec.ts`
