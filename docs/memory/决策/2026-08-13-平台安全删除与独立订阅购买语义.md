# 平台安全删除与独立订阅购买语义

## 决策

- 平台只允许“安全删除”：账号、API Key、使用记录、审计记录、运维记录或平台范围配置存在任一引用时，删除返回 `PLATFORM_IN_USE`。
- 不提供强制删除，不自动解绑，不清除或置空历史记录。平台自身的模型规则随平台删除。
- 管理端“订阅套餐”入口改名为“上架订阅”。
- 再次购买同一套餐会创建一份新的独立订阅，不延长原订阅时长；多份订阅并存并按系统既定顺序使用。
- 重复购买按钮使用“再来一个”，不使用“续费”。

## 实现边界

- 后端 `PlatformManagementRepository.DeleteUnused` 在同一 PostgreSQL 事务内锁定平台、检查引用并删除。
- 安全删除必须兼容历史部署中未安装的可选运维表：存在时纳入锁定与引用计数，不存在时按零引用处理；不得因可选表缺失返回 500，也不得放宽其他业务、审计或运维引用检查。
- `DELETE /api/v1/admin/platforms/:id` 只透传安全删除结果。
- 前端平台页必须二次确认，并本地化显示引用分类计数。
- 充值/订阅页面在套餐列表与订单确认阶段都展示独立叠加说明。

## 验证

- 后端：Platform service/repository/admin handler/routes 单元测试。
- 生产数据库：在只读事务中验证可选表探测、现存引用表锁定与完整引用计数 SQL。
- 前端：平台删除、套餐卡、支付页、订阅页、侧边栏与中英文文案测试；typecheck、lint、production build。
