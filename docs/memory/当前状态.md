### 进行中

- 代码与发布通道已完成，当前等待用户部署并测试 `my2-v0.2.0`；未经测试确认，不把该重构提升到 `my` 正式交付分支。

### 已完成

- `BillingProfile` 独立保存余额倍率、峰时和媒体价格；`SubscriptionPlan` 保存套餐时长、日/周/月额度与倍率；`UserSubscription` 固化套餐快照并允许同组多实例。
- 请求按 API Key 分组顺序、平台与端点能力选择可用套餐实例；同组实例按最早到期、再创建时间使用，套餐都不可用时回退余额。
- 用量、缓存和扣费均以实际 `subscription_id` 归属；套餐实例倍率优先于余额倍率，用户专属余额倍率仅保留旧数据兼容，RPM override 继续生效。
- 修复可选订阅服务传入 typed-nil 接口导致的网关 panic；无订阅服务时安全回退余额。修复 `/v1/sub2api/billing` 在余额不足或套餐失效时仍应只读放行。
- 订阅摘要卡展示套餐名称、到期时间、当前额度窗口、进度和余量；无额度套餐显示不限额。
- 订阅 API 失败时回退为空卡片列表，不影响仪表盘其余数据。
- 已恢复 `AppLayout` 覆盖的旧版暖色背景层，并新增回归测试固定三项样式契约。
- 已恢复 Tailwind 和全局样式中的暖色主题，并补齐订阅摘要文案，避免显示内部翻译 key。
- 本次关联的前端 Vitest 21 个文件、173 项断言通过；类型检查、lint 和生产构建通过。完整 Vitest 仍被本机缺少已声明的 `@intlify/message-compiler` 及两个未改动 rollback 测试的旧断言阻断。
- 官方同步已引入 OpenAI 转发、订阅配额、使用统计、模型广场和安全相关更新；`my` 保持官方功能行为。
- API Key 合并同时保留多套餐 `group_ids`、可不绑定分组、首分组兼容 `group_id`、缓存端点能力，以及官方的部分字段更新保护。
- 用户密钥页面仍使用多套餐复选列表，禁止恢复表格内单分组下拉修改；修复并测试 `GroupOptionItem` 导入。
- 发布流程仍由 `v*` Tag 触发，生成 `sub2api_latest.tar` 与 SHA256；Dockerfile 同时复制官方运行资源并保留减少 `chown` 层的优化。
- 已推送 `my2.0` 与 `my2-v0.2.0`；独立 `My2 Preview Release` 成功生成 GitHub prerelease、GHCR `my2-latest`/`my2-0.2.0` 和 `sub2api_my2_latest.tar`。下载资产后已验证 SHA256，且 Docker save 清单不含正式 `sub2api:latest`。

### 最新修复

- 多套餐订阅在优先套餐用尽后，会立即失效订阅认证缓存，并在下一次请求中跳过已达日、周、月限额的套餐，继续选择下一个可用套餐或余额分组。
- 已确认移除用户专属余额倍率；RPM 覆盖功能单独保留。
- `/v1/sub2api/billing` 仅做鉴权与分组可用性检查，不读取订阅、不检查余额/额度且不更新 API Key 最后使用时间。
