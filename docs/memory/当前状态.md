- 完成九任务实施计划，依次覆盖迁移、Platform API、账号调度、上游映射、模型列表、平台 UI、账号 UI、持久化审计和全量验证。

- 平台运行时统一使用平台模型规则、端点能力和平台账号池；平台授权 Key 的 `/v1/models` 只返回授权平台的启用模型。
- 创建、编辑和批量编辑账号不再提供普通模型白名单、普通模型映射或 Chat/Responses 端点策略；Compact 专属映射和适配器技术能力仍保留。
