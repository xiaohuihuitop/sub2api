### 最新修复

- 多套餐订阅在优先套餐用尽后，会立即失效订阅认证缓存，并在下一次请求中跳过已达日、周、月限额的套餐，继续选择下一个可用套餐或余额分组。
- 已确认移除用户专属余额倍率；RPM 覆盖功能单独保留。
- `/v1/sub2api/billing` 仅做鉴权与分组可用性检查，不读取订阅、不检查余额/额度且不更新 API Key 最后使用时间。
- 腾讯云测试服务器使用隔离标签 `sub2api:my2-0.2.0`，未覆盖正式 `sub2api:latest`；升级前备份位于 `/opt/sub2api/backups/before-my2-v0.2.0-20260804T064745Z`，迁移后数据库归档位于 `/opt/sub2api/backups/after-my2-v0.2.0-20260804T065332Z`。
- 腾讯云测试服务器已移除 `api.xhhtop.top` 的 Nginx 站点、本机 Certbot 证书及默认 HTTPS 证书引用；仅保留 `/etc/nginx/sites-available/sub2api-ip-test` 中匹配 `43.134.56.76` 的 HTTP 测试入口，并反向代理到 `127.0.0.1:8080`。测试使用 `http://43.134.56.76`，不要直接暴露 Docker 的 8080 端口；裸 IP HTTP 不具备 TLS 保护，不用于敏感或正式流量。
