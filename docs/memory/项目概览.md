# 项目概览

- 项目：Sub2API 的长期定制分支。
- 主交付分支：`my`；官方同步来源：`upstream/main`。
- 订阅与计费重构开发分支：`my2.0`，基线为 `my` 的 `v0.1.171` 发布提交。
- 原则：功能默认跟随官方，保留用户确认的 UI 和调度定制；同步官方后按决策记录恢复。
- 计费边界：账号分组只负责账号与路由；`BillingProfile` 负责余额倍率、峰时和媒体价格，`SubscriptionPlan` 负责套餐时长/额度/倍率，`UserSubscription` 保存发放时快照并允许同组多实例。
- 调度与兼容：先按 API Key 分组顺序、端点能力和套餐实例可用性选择订阅；订阅不可用时回退余额。`group_id` / `group_ids` 保持兼容，旧 `Group` 收费字段仅作迁移期适配；用户专属余额倍率不参与计费，RPM override 保留。
- UI 约束：暖色主题由 `tailwind.config.js`、`style.css` 和 `AppLayout.vue` 共同定义，三者必须同步保留。
- 前端：Vue 3、TypeScript、Vite、Vitest。
